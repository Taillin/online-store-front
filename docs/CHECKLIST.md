## Выполненные проверки

- JavaScript прошёл синтаксическую проверку Node.js; локальные href/src существуют, ID не повторяются.
- Chrome: пять страниц × две темы × три ширины (375/768/1440 px).
- Тема сохраняется при обновлении и переходе между страницами.
- Пустые и неверные данные входа отклоняются; корректный профиль сохраняется; выход удаляет только профиль. Паролей в localStorage нет.
- Повреждённый JSON профиля не ломает страницу.
- Шесть FAQ открываются/закрываются; aria-expanded и значок соответствуют состоянию.
- Реальные запросы DummyJSON возвращают товары; смена категории и обновление работают.
- Отдельно имитировались HTTP 503, пустая выборка и неверная структура JSON. Показаны правильные сообщения; после снятия имитации повторный реальный запрос успешен.
- Старые поиск+фильтры, CRUD, сохранение списка, галерея и валидация форм проходят проверки.
- На проверенных размерах нет горизонтального переполнения страницы, сломанных локальных фотографий и необработанных JavaScript-ошибок.

Скриншоты сняты с локального HTTP-сервера; данные API получены из живого сервиса. Эти проверки не гарантируют оценку и не заменяют индивидуальную защиту.

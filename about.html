About IAIDev

A student project for browsing and comparing computer hardware.

Who are we?

IAIDev is a student store website for our Front-End Web Development course.

We built a simple place to browse laptops and PC parts. Visitors can search products, compare specs and save a personal list.

4 Product groups on the home page
5 Connected pages
100% Responsive layout
8+ Product examples

Our tools

We use the tools we studied in class:

  • 🔹
    HTML5: elements <header>, <nav>, <main>, <section>, <article>, <footer>.
  • 🔹
    CSS3: color variables in :root, positioned badges, :hover and :focuseffects, and :nth-child(even) for table rows.
  • 🔹
    Layout: the menu uses Flexbox, product cards use CSS Grid, and page columns use Bootstrap 5.
  • 🔹
    JavaScript and jQuery: forms, search, product lists, gallery, FAQ, themes, profiles and API data. We use @media rules to fit smaller screens.
